# 0.1.3 闹钟待办改进（2026-10-06）

这次解决待办时间设置复杂和到点提醒不明显的问题。默认页面改为闹钟卡片；新事项填写名称、选择日期时刻、保存即可，默认到时间提醒。原文确认、仅日期、操作类型、备注和自定义提醒保留在“更多设置”。默认紧凑编辑器为690×350，展开更多设置时增加高度，保留用户调整的宽度。个人时间通过点击保存确认；原文时间仍需明确核对与证据。

卡片显示完整年份、日期时刻及真正计算的提醒时刻，保留完成、撤销、修改、取消恢复及关联通知。默认视图为卡片，可切回列表；搜索、筛选和选中事项在两视图间一致。已有关闭、自定义、仅日期、非零秒、状态和日历UID不改写。

## 到点提醒与运行边界

- 生产调度每1秒检查。最近5分钟内尚未投递的有效提醒，在启动、当前分钟新增、重新启用和短暂停顿后仍可触发；更早的提醒记为过期。同一事项与UTC触发时刻只投递一次，改期可产生新的提醒。
- 独立非模态置顶窗口保留多条提醒，直到用户点击“知道了”或关闭窗口。关闭提醒不自动完成待办。“查看待办”返回事项；其他学校的事项保留提醒并提示切换学校。
- “测试提醒”直接使用正式展示路径，不创建假任务，不写提醒投递表。相同的持续存储错误只显示一次，避免每秒堆积错误窗口。
- Windows托盘可用时关闭主窗口仅隐藏，继续运行；托盘菜单提供打开、我的待办、测试和彻底退出。彻底退出、关机和睡眠期间不检查；再次运行只适用上述5分钟补发窗口，没有开机启动或系统常驻服务。
- `submitted`表示通道调用完成。应用内窗口可见、系统横幅已送达和用户已读分别判断，不能互相代替。
