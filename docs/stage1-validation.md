# 第1步：来源管理、状态与官网输入

日期：2026-10-02。当前交付包含“通知”“来源”“大学”三个页面；第2步保存订阅、第3步个人待办、第4步内置日历与ICS仍待实施。

## 已实现行为

学校包保留完整目录与可执行配置，未接入来源只展示。来源状态和本机暂停分别保存；每轮按学校/来源记录起止时间、页面条数、错误和最近完整成功，历史运行最多保留30轮。第二页失败形成部分成功，成功页面和旧缓存保留；中断重启可重试。已有缓存不会被当成一次历史抓取，首次迁移不伪造尝试或成功时间。

官网输入先匹配已安装学校包的完整官方首页主机，校验阶段不联网，匹配后加载对应学校配置。支持完整首页URL或域名；拒绝未收录网站、伪装主机、IP、本地地址、账号、显式端口、路径、查询、片段和编码伪装。允许域和重定向约束继续适用于实际采集。学校包目录是维护者审核的信任边界，任意`.edu.cn`网址不会自行加入白名单。

目前仅东电学校包完成接入。其他高校需要维护者核验身份、官方首页与各栏目配置；同一输入页面和通用服务无需按学校另写一套界面。尚未实现根据任意官网自动发现所有栏目与自动生成解析选择器。

## 源码边界

`domain/Source.h`存纯C++数据；`application/SourceService`负责目录和来源用例；`storage/Database`、`SqliteMigrations`、`SqliteSourceRepository`负责连接、迁移和参数化SQL；`adapters/RefreshCoordinator`负责有限网络队列和进度；`UniversityRegistry`负责官方首页目录匹配；桌面页面负责展示和用户输入。

数据库长会话使用[Qt QLockFile](https://doc.qt.io/qt-6/qlockfile.html)防止两个窗口同时使用同一库并误判中断。程序目录内的学校配置来自受信任的发布包；输入校验不代表能证明被人为篡改的本地配置属于高校。

程序包入口为[CampusPulse.exe](../dist/CampusPulse/CampusPulse.exe)，使用整个目录。运行不需要Python或Qt SDK；当前机器验证，未公开发布。来源按用户操作更新，没有无人值守采集、保存订阅、个人办理期限或手机日历提醒。
