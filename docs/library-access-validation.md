## 软件与数据

资源详情现在独立展示“用途与使用条件”和“说明出处”。`access_note` 保存有日期、范围及未知项的说明；`access_evidence` 保存单条学校公开HTTPS出处。普通发现更新保留已审核说明与收藏；访问检查失败不会清空历史说明，历史说明也不会把当前访问失败改成成功。

“入口可访问”只表示取得可读的公开页面。浏览器脚本壳、登录入口、403、网络超时分别保留说明，不把脚本无法读取误报成网站永久不可用。登录资源按学校或提供方说明操作，不统一要求学号。说明出处按钮再次检查本校域及精确记录URL，网页摘录和说明按文字转义显示。

数据库升级到版本7，只向资源表增加两列；升级、刷新及重新启动的离线测试覆盖原表、资源身份、收藏和说明保留。生产导入还检查每个资源的学校发现出处及每个使用说明的本校证据URL。

## 证据与复现

本轮已有21项资源参与核实，另从实际学校HTML新增CAJViewer、Adobe Reader、SSreader和CARSI学校入口，共核实25项，合并样本由90项增至94项。其中13项取得可读公开页面，2项识别为登录入口，2项静态正文不足，8项因当前DNS返回非公网地址被请求安全门拒绝。其余69项保留缓存，本次没有重新核查。

12条学校说明对应8个唯一学校证据页，均取得本次HTTP200可读正文；15项资源保存了用途与使用条件。23份原始公开响应的SHA-256已逐份核对。合并数据已通过C++资源服务导入独立数据库与本机默认数据库，版本7迁移前后的9张原有业务表内容/结构哈希一致，原有各校资源身份和收藏保留。

C++全套17组测试通过；调整说明在详情中的显示顺序后，重新通过资源界面测试。DS契约41个离线反例测试通过。桌面2原生资源界面验收使用真实核实缓存副本，94项列表和实际说明匹配；当前虚拟桌面、前台窗口未变，没有键鼠操作、打开浏览器或模型请求。证据在 `evidence/library-access/` 下的 `resource-native.json/png`、`default-before-import.json`、`default-after-import.json`；软件包启动结果汇总在 `delivery.json`。

正常软件包在桌面2启动成功，保留用户选择的北华大学。北华当前没有通知缓存，程序按已有启动行为更新公开来源，新增11条采集运行日志并更新来源状态；不能把启动后的全库哈希一致当作验收条件。迁移/导入阶段9张原业务表完全一致，正常启动后通知、修订、来源归属、订阅、待办、提醒记录、来源偏好7张表以及原有资源身份/收藏仍一致。这个区别记录在 `normal-boot-data-preservation.json`，最初完整哈希检查失败的记录也保留，没有改写成全库不变。

学校说明人工核实记录为 `evidence/library-access/annotations.json`。其中 `source_access_checked=true` 表示本轮通过网页工具实际读取公开学校证据，不能解读为登录或全文授权成功。独立HTTP脚本遇到网络差异时，另存脚本读取结果，不改写这一记录。

手动公开入口审计使用 `tools/verify-library-links.py`，范围固定为本次东北电力样本，不能作为全国高校通用采集器。它读取实际学校HTML链接并保存原始地址与安全规范化关系，限量请求公开HTML/text、限制重定向和体积，不发送登录表单。第三方入口检查只在显式运行该开发工具时执行，通用 `ResourceDiscovery` 的默认行为仍不访问第三方。

```powershell
py -X utf8 tools/verify-library-links.py --report evidence/neepu-resources-live.json --annotations evidence/library-access/annotations.json --output evidence/library-access/run-20261003
```

脚本的DNS预检不固定实际连接地址，有限域名规则也不是通用公共后缀库；它只用于这次受限公开入口审计。通用服务端接入时需在实际请求层实现相应网络边界。原始响应与HTTP结果见 `evidence/library-access/run-20261003/audit.json`，合并资源见同目录 `report.json`。开发工具不导入生产库；生产导入由C++资源服务执行。

AI说明的输入、固定字段、引文、unknown及草稿边界另见[资源AI契约](ai-resource-contract.md)。本轮人工说明和HTTP核实不消耗模型token，新资源AI接口尚未接入界面；不能将离线校验成功当作DS实际调用成功。
