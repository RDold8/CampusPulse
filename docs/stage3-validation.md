# 第3步验收记录

2026-10-02。已完成个人待办、用户确认时间、办理状态及原文复核；第4步的日历、ICS和实际提醒投递尚未实现。

## 交付

通知详情增加“加入我的待办”和“刷新原文”；新增“我的待办”页面及任务编辑器。一条通知可手动建立报名、缴费、申请、核对结果、参加活动等多个独立事项；支持搜索、状态/日期筛选、编辑、开始、完成、撤销完成、取消、恢复和跳回关联通知。通知、订阅及采集不会自动创建或完成任务。

时间区分日期待定、仅日期和准确时刻。已知时间由用户确认，摘自原文的时间需填写说明；仅日期不补出时刻，准确时间按学校时区输入和显示、以UTC保存。修改时间、来源或说明需重新确认。已完成或已取消事项不显示逾期，撤销或恢复后按实际时间重新判断。

任务UUID、创建时间、日历UID保持稳定，有效修改递增修订，原样保存不增加版本；过期编辑与学校范围错误拒绝保存。SQL存储使用参数绑定、外键与事务。原文修订变化后提示复核，保留个人状态和确认日期；核对按钮只更新参考修订，不自动改期。提醒选项当前只保存偏好，界面直接说明日历阶段启用后使用。
