# 学校资源

学校资源收集高校官网公开提供的学习资料和实用入口。东北电力大学是当前采集与界面验收的示例；分类、存储、发现和界面共用通用模块，社区可以给其他大学添加资源入口。

## 使用

在“大学”页加载学校，进入“学校资源”。已有缓存立即显示；首次进入且缓存为空时，后台发现一次。可以按类别、学习阶段和关键词筛选，收藏常用入口，或者点击“后台发现资源”重新检查。发现期间仍可查看缓存、筛选和收藏，也可取消。

默认显示全部类别和全部学习阶段。类别包括学习规划、课程资料、图书馆、竞赛、学术支持、办事服务、就业、校园服务和其他。标题或官网栏目无法明确说明适用阶段时，标记“适用阶段待核实”；不会据此推断你满足报名或使用资格。

选中资源可查看名称、用途、提供方、学校官网发现出处、访问状态和最近检查时间。已核实的资源还显示用途与使用条件，以及对应的学校说明出处。点击“打开资源”交给系统浏览器；需要登录时按学校或提供方说明操作。软件不读取账号密码，也不复用浏览器登录会话。

## 状态与边界

“入口可访问”表示检查成功取得有效公开网页，不代表学校购买全部内容或个人获得全文权限。“已发现 · 待核实”表示已经从官网找到链接，但尚未完成访问检查。超时、异常状态码、无有效内容等显示“入口检查未通过”，保留资源和错误说明；自动检查受限也可能仍可在浏览器、校园网或机构认证后访问。

学校官网推荐的外部资源保留官网出处，未经检查时标记“外部官网推荐 · 未验证”。自动发现不访问第三方站点；开发期手动核实公开入口可以记录检查结果，这种结果只表示入口状态。附件和文件入口只保存链接，不自动下载大型文档或学生名单。

用途与使用条件独立存为 `access_note` 和 `access_evidence`，普通发现刷新保留已审核说明。说明中保留学校文件日期、采购范围、试用期限和待确认项；学校旧说明不能证明当前合同仍有效。校外访问、手机号或学校账号要求也以对应学校说明为准，不统一猜成学号登录。东北电力图书馆核实见 `docs/library-access-validation.md`。

资源不按照通知的发布日期分年：培养方案、数据库和办事入口可能长期有效，最近检查时间不代表发布日期或办理截止。有关申请、缴费、竞赛报名的期限仍须核对通知原文并加入个人待办。

## 通用配置与发现

学校配置可添加以下可选字段。东北电力示例使用已有公开入口作为发现起点，旧配置没有该字段仍可加载。

```json
"resource_discovery": {
  "department_urls": [
    "https://lib.neepu.edu.cn/",
    "https://jwc.neepu.edu.cn/rcpy/pyfa.htm",
    "https://jwc.neepu.edu.cn/fwzn/xsfw.htm"
  ],
  "max_pages": 32
}
```

入口必须是本校 HTTPS 地址。发现流程从官方首页、公开部门入口与学校包已知栏目提取链接，识别学习和服务用途，再访问有限数量的校内页面。默认每轮至多 32 个请求、请求间隔 3 秒、单次超时 8 秒、响应上限 2 MiB、深度上限 3。取消或部分失败保留已经入库的资源；该范围不代表学校所有资源已经找全。

这条流程使用 HTTP 和 HTML 解析，不加载浏览器页面，不调用模型，默认不消耗 API token。AI 补充栏目功能仍由原独立入口控制。

生成过的通知配置可以从已安装的同校社区包继承资源发现入口，不覆盖用户已经生成的通知来源。资源记录和收藏按学校隔离；更新官网内容保留收藏状态。

## 源码阅读与数据契约

| 层 | 入口 | 职责 |
| --- | --- | --- |
| 领域 | `src/domain/SchoolResource.h` | 资源、查询及仓库接口，不依赖界面 |
| 应用 | `src/application/ResourceService.cpp` | 校内隔离、数据验证、筛选和收藏 |
| 存储 | `src/storage/SqliteResourceRepository.cpp` | 原子更新、持久收藏与 SQLite 读写 |
| 适配 | `src/adapters/ResourceClassifier.cpp` | 地址校验、用途与阶段提示 |
| 采集 | `src/adapters/ResourceDiscovery.cpp` | 有界异步发现、访问检查、官网证据 |
| 界面 | `src/desktop/ResourcePage.cpp` | 缓存展示、筛选、详情与操作 |

数据库版本 7：版本 6 新增 `school_resource` 表及索引，版本 7 在资源表增加用途与使用条件、说明出处两列。不改通知、订阅、待办或提醒记录，保留原有资源身份和收藏。资源的稳定身份来自学校 ID 和规范化地址。字段包括名称、地址、描述、用途与使用条件、说明出处、类别、提供方、适用阶段、标签、官网发现出处、检查时间、访问状态、链接类型、错误和个人收藏。

资源更新不会创建通知、修改个人待办或自动推断截止时间。移动端未来可以使用同一资源与查询契约；当前版本没有手机同步。

DS 资源说明契约使用程序已抓取的公开片段作为输入，只输出有引文的草稿；JSON 和引文校验不认证语义、学校采购或个人权限。协议、提示词和离线验证工具见 `docs/ai-resource-contract.md`。现有 AI 界面仍用于可选栏目搜索，资源说明 API 尚未接入界面。

## 验证入口

配置检查使用 `py tools/validate_school_configs.py`；构建脚本运行资源数据、发现边界和 GUI 契约测试。实网采集与桌面 2 原生界面另存证据，见 `docs/school-resources-validation.md`。离线测试与实网结果分别记录。
