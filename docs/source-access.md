# 需要学校账号登录的来源

来源列表将“需要登录”与一般“待接入”分开。页面上方显示需登录来源数，点击“查看需登录来源”可依次选中这些来源；选中后显示账号登录说明、已经核验的官方地址和“打开官方登录入口”按钮。

长春理工大学本科教务入口为 `https://jwc.cust.edu.cn/`，由系统浏览器处理学校自己的统一身份认证跳转。学校账号、密码和验证码在官方网页输入。CampusPulse 本轮只提供官方入口，不接收或保存密码，也没有连接浏览器的登录会话；浏览器登录后，软件不会自动采集受限通知。需要登录的来源不能更新或恢复采集。

## 社区学校包

来源可选声明以下访问元数据，其他大学使用同一契约，无需在界面中增加大学分支：

```json
"access": {
  "mode": "login_required",
  "login_url": "https://jwc.cust.edu.cn/"
}
```

`mode` 支持 `public` 或 `login_required`。登录地址必须为学校官方域内的 HTTPS 地址，并在该来源允许主机中；不接受含认证信息或显式端口的地址。无有效官方入口时，不提供可点击登录按钮。禁止在社区学校包中填写个人账号、密码、Cookie 或令牌。

自动接入识别到登录页面时，会保存 `login_required` 元数据和原始官方入口，同时保留待接入原因并关闭采集。已有缓存包如果明确记录“需要登录”，加载器兼容识别并校验入口，无需改写缓存或重新扫描学校。403、502 等请求失败单独保留，不会据此推定必须登录。

## 本轮验证

界面契约检查使用拦截的浏览器请求，确认按钮只请求已核验官方地址；不会真的打开用户浏览器。公开来源隐藏登录卡片，未知入口禁用按钮，点击入口和重新加载不会启用采集。

原生验收使用长春理工大学现有缓存包、独立临时数据库和桌面2的生产界面，不发起采集、模型请求或实际登录。证据见 `evidence/source-access-native.json`、对应截图及 `evidence/source-access-build-tests.log`。实际账号登录和已登录采集尚未实现；本轮验证不代表这两项已完成。
