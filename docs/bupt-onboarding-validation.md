# 0.1.2：北邮目录外大学接入验收

2026-10-04，针对输入 `https://www.bupt.edu.cn/` 后 HTTP 412 导致学校识别失败的问题，修复通用传输与栏目发现。不新增北邮专用学校包，不依赖模型调用。

## 已复现的原因

0.1.1 独立未知大学探针在首页身份校验阶段失败；同机通过正常域名发出普通 HTTPS 请求也得到 HTTP 412 和约2.5KB的 JavaScript 浏览器验证页。更换常见浏览器请求头仍失败，说明不能只靠改 User-Agent 或加入本地学校目录来解决。

## 修复范围

普通采集保持直接 HTTP。遇到识别到的公开网页验证时，Windows 使用独立 WebView2 临时会话，保留本校 HTTPS、公网 DNS 与证书校验，验证取得真实 HTTP200 页面后继续采集。公开会话 Cookie 与 User-Agent 按主机在内存短期使用；不读取个人浏览器、教务账号或模型密钥。运行时未随安装器分发，缺失时需要从微软官方入口安装 WebView2 Runtime。

通用规则补充部门首页列表识别、图标导航标签、教学与通知栏目优先级、同校正文跳转主机记录。分页历史不作为新栏目；扫描报告保存预算耗尽与未访问入口。陌生学校默认发现预算从24提高至48，仍保持请求间隔和验证门槛。分离显示的年月、日期须有明确且唯一的日期节点，不能借用标题学年或正文活动日期。

“教务处概况”等页面可作为学校资源验证；通知来源说明明确它不是通知列表。它无需满足三条通知的列表要求，但资源仍须检查官网出处与页面可读性；没有放宽通知来源的正文校验。

## 实网证据

修复后独立探针已正确识别“北京邮电大学”，24次请求验证9个列表入口、113条累计列表记录，模型调用0次，正常退出。该早期记录包含分页入口，后来规则已排除。生产界面通过实际输入北邮官网完成一次24页接入：7个验证列表入口、127条累计记录，刷新后数据库113条去重信息。其中16条明确为2026年、87条日期待核实，其余为2024/2025年。多个首页、栏目可以包含重复文章，列表累计条数和数据库去重条数不能互换。

扩大主题导航前，在桌面2启动完整部署包，使用独立数据库、设置与学校草案目录，实际输入北邮官网，未加载北邮专用包。默认48页预算实际请求37次，验证12个列表入口、182条累计列表记录；队列处理结束，预算未耗尽。通知刷新后保存154条去重信息：32条明确为2026年，107条日期待核实，另外15条为2021/2023/2024/2025年。原生通知页默认显示2026年的32条；不能把缺少发布日期的记录归入今年。

原生“学校资源”页完成一次有界发现，保存47项入口，其中7项已检查可访问，40项仅已发现、待核实。“教务处概况”实际地址为 `https://jwc.bupt.edu.cn/jgsz/jwcgk1.htm`，官网发现出处为 `https://jwc.bupt.edu.cn/`；数据库状态为 `verified`，界面显示办事服务、入口可访问及官方链接。已查看原生界面截图，不能以发现47项代替验证47项。通知页另选一篇文章验证正文读取，结果保存在本机验收记录。

本机记录：`evidence/bupt-0.1.1-baseline.json`、`evidence/bupt-0.1.2-fixed.json`、`evidence/release-0.1.2/ui/`、`evidence/release-0.1.2/ui-final/acceptance.json` 及原生界面截图。这些证据、网页样本与数据库不进入源码或软件包。最终流程模型调用0次。队列处理结束仅说明本轮规则发现结束，不代表全校全量；就业网动态列表、团委页面及受限财务入口仍有明确失败记录。

## 主题遗漏复查

154条快照中重修、补考、缴费标题各为0条，竞赛分类仅4条，标题含“通知”51条。检查实际教务处首页发现“双创教育”链接到本校另一子域，旧规则没有跟进；竞赛栏目也未必作为列表候选。随后补充这些共享导航规则，并对验证到常见 CMS/标准下一页的来源启用最多3页更新；外国域的下一页不能扩大来源允许域。

最终再次使用全新本机草案、独立数据库与设置，在桌面2实际输入北邮官网。发现阶段使用48次请求，验证15个列表入口、206条累计列表记录，预算已耗尽，报告保留未访问入口与深度限制，`discovery_complete: false`。7个来源验证到分页。更新完成后15个来源成功，保存302条去重信息，50条明确为2026年、153条日期待核实；竞赛分类增加至28条，其中10条明确为2026年，包括智能机器人创意大赛及睿抗机器人开发者大赛报名通知，类别仍按关键词提示，不等于全部都是报名事项。标题含“通知”152条。随后学校资源有界发现45项，其中5项已检查可访问、40项仅已发现，包含已验证的“教务处概况”；扩大导航后请求预算分配发生变化，两轮资源数量不能合并为全量覆盖。

重修、补考的当期通知仍未验证到。新增缴费标题1条，是校医院缴费流程，与重修缴费无关。学校公开的[重修选课说明](https://jwc.bupt.edu.cn/info/1254/2768.htm)发布于2021年，要求学生查看每学期信息门户教务处发布的具体流程；这是一份公开办理说明，不能用它替代2026年的报名、缴费时间，也不能承诺公开爬虫读取需要账号的门户内容。校园学院站点、更多历史页和纯动态列表仍有覆盖缺口。最终记录在 `evidence/release-0.1.2/ui-expanded/` 与发布清单。

## 验收与边界

Release 构建、21套 CTest、5份学校配置检查通过。离线回归验证未知输入与网络边界、至少三条列表加首条正文的启用门槛、优先队列、图标标签、分页排除、日期证据与部门资源分类；不会在 CTest 里访问学校网站或收费 API。

本次没有调用真实 AI API。公开浏览器验证只在 Windows 提供；人工验证码、学校账号登录、纯动态列表、特殊模板仍可能需要适配。48次请求不代表全校全量或历史全量。手机日历导入、系统通知送达、原地安装升级均未在本次实测。
