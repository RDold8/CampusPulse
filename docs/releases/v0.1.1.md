# CampusPulse 0.1.1 · Windows 桌面预览版

这次更新在0.1.0基础上，继续围绕“更容易找到学校官网的信息，减少漏看报名、缴费和申请通知”改进。

## 本次更新

- **目录外大学发现**：在“大学”页输入尚未收录的 `.edu.cn` 根域或 `www` 官方首页，可尝试识别学校并发现公开部门、栏目和资源入口。生成本地待核验草案；新来源仍须通过列表与首条正文验证，失败保留原学校。
- **AI 提供方配置**：支持多套提供方、可自选 HTTPS 请求地址、完整 URL、Anthropic Messages / OpenAI 兼容格式、认证方式、模型获取与显式连接测试。默认密钥只保留在进程内，Windows 可选择当前用户 DPAPI 加密保存。
- **更简洁的主页面**：主 AI 页面只选择模型；路由和密钥集中在提供方编辑窗口。单独保存模型保留已有密钥。
- **八类搜索模板**：综合栏目、重修补考缴费、奖助学金申请、竞赛创新创业、校园活动、学习资源、教务培养、就业招聘。各类使用不同部门与关键词提示词，按学校记住选择；候选链接继续由官网爬虫验证。
- **搜索结果与自动调用修复**：保留已返回的真实部分搜索结果并显示工具次数上限；关闭自动补充会取消尚未执行的排队调用。不自动续接收费请求。

## 下载和使用

Windows 10 1809+ / Windows 11 x64。安装包按当前用户安装；便携包需要完整解压后运行 `CampusPulse.exe`。运行不需要 Python 或 Qt SDK。

- `CampusPulse-0.1.1-windows-x64-setup.exe`：安装程序。
- `CampusPulse-0.1.1-windows-x64-portable.zip`：便携版。
- `SHA256SUMS.txt` 与 `release-manifest.json`：文件校验与本次验证范围。
- Qt Base、Lexbor、libical 源码附件：对应依赖源码；完整许可随应用提供。

本版本沿用 0.1.0 的安装身份及独立用户数据目录。安装前请自行关闭正在运行的 CampusPulse；卸载保留个人数据库与设置。本次没有覆盖现有安装执行升级验收，具体状态见发布清单。

## 已验证及当前边界

Release 构建、21 套 CTest 和 5 份学校配置检查通过。主页面与配置表单已在 Windows 桌面2使用独立数据检查；主页面没有路由或密钥字段，八类模板进入实际请求构造。本轮发布不包含真实密钥、用户数据库或日志。

此前真实 DeepSeek 模型列表及短连接请求成功；原生搜索收到真实工具结果和次数上限。修复后的完整搜索到来源接入链、新分类模板搜索效果，以及一个目录外大学从输入到可用通知的完整流程仍待实网复验。模型建议不代表已联网搜索；支持普通模型响应的服务也可能不支持搜索工具。各校来源覆盖有限，登录、动态栏目和访问限制可能需要社区适配。手机同步尚未实现，手机 ICS 导入和系统通知送达仍需目标环境验收。

初版，有许多不足之处，请见谅。

# CampusPulse 0.1.1 · Windows desktop preview

Building on 0.1.0, this update makes official university information easier to find and helps students keep track of registration, payments, and applications.

## Changes

- Discover universities outside the bundled registry from `.edu.cn` root or `www` official homepages. Identities remain local unreviewed drafts; sections need list and first-article verification.
- Configure multiple AI providers with custom public HTTPS routes, full URLs, Anthropic Messages or OpenAI-compatible APIs, authentication modes, model lists, and explicit connection tests. Keys are session-only by default, with optional current-user Windows DPAPI encryption.
- Select models on the main page; edit routes and credentials in the provider dialog. Saving a model preserves its credentials.
- Use eight category-specific search templates for general discovery, retakes and payments, financial aid, competitions, campus activities, study resources, teaching administration, and careers. Selections are saved per university; candidates still require website validation.
- Retain valid partial tool results when the search-use budget is exhausted, and cancel queued automatic supplementation when it is disabled. No automatic extra paid requests.

## Downloads and verification

Windows 10 1809+ / Windows 11 x64; no Python or Qt SDK is needed to run the application. Use the per-user installer or extract the complete portable ZIP. Checksums, a release manifest, dependency sources, and component licenses are included.

The Release build, 21 CTest suites, and five school configuration checks passed. Native UI checks used isolated data on Windows desktop2. This release includes no real API key, personal database, or logs. The existing 0.1.0 installation was preserved; an in-place installer upgrade was not tested in this release.

Real DeepSeek model-list and short connection tests previously succeeded. The repaired search-to-source workflow, category search quality, and complete onboarding of an unconfigured university still require live rechecks. Compatible model suggestions are unverified. Coverage, authenticated or dynamic sites, mobile synchronization, phone ICS import, and notification delivery retain the limitations described in the project documentation.

This is an initial version with many shortcomings. Thank you for your understanding.
