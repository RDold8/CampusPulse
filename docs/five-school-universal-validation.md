# CampusPulse 通用采集整改与五校实网对比

本轮已修改共享采集代码，并以东北大学、大连理工大学、哈尔滨工业大学、山东大学、南京邮电大学复测。五校不在原有学校包目录内。启动接入只提供官网首页，不增加学校种子、不手工添加栏目、不调用 AI。

测试时间为 2026-10-04 至 2026-10-05，时区 Asia/Shanghai。独立官网盘点与软件采集在不同时刻进行，网页可能更新。Windows 桌面2使用隔离数据库和设置；桌面1的软件与资料未修改。只读查看页签用于观察进度，不改变采集参数。最终轮东北大学和哈工大首次身份请求超时，保存失败记录后仅用相同网址重试一次，未更改DNS、代理或其他网络设置。

这是一份有边界的公开信息对照：五校共记录 1482 个独立官网 URL，覆盖首页、已访问的部门与栏目、部分学院以及图书馆等入口；没有穷举全校所有学院、全部历史页面和校内账户系统。

## 实际修复

1. 统一识别 WebPlus 的 c…a…/page.htm、VSB 的带 wbnewsid 的 JSP 和 Drupal 的 article/event URL；首页卡片、div、表格单元和日期拆分结构使用共享解析。文章链接不再当成导航栏目，菜单及页脚档案不混入通知行。
2. 通用部门词补充本科生院、学生指导、资助、计划财经、内设机构等；进一步纳入学部学院、院系目录、主校区导航与迎新网，发现并非挂在职能部门目录下的创新创业及新生缴费信息。图标与“更多”链接从附近唯一栏目标题取得语义。以目录、通知与办事栏目为先，按主机已请求数分配机会；队列满时也考虑已访问主机，避免同一主机的大型菜单挤掉未访问部门。
3. 多入口或重定向抵达同一来源时合并来源标识，修复山东大学配置加载时“重复的来源标识”。只有列表至少三条并验证一条公开正文才启用；单篇受限时最多选择同一列表的三篇正文，不将整份公开列表判为登录受限。
4. 部门首页的宣传轮播可位于真实通知之前。正文校验优先选择重修、补考、缴费、申请等办事内容，结合明确发布日期排序；不再只验证DOM最前面的三张宣传图片。补充实际轮播与通知共存样本及原失败操作复测。
5. 已经在自动接入阶段校验的正文、附件和明确发布日期直接保存到通知库，不再次请求。正文补足发布日期后，列表缺少日期不会抹掉它。列表的月日、标题学年、网页URL中的年月日不自动充当发布日期。
6. 接入完成后的通知更新自动接续学校资源发现，避免只输入官网时资源仍为空。权限提示、校园网限定页、空白页、动态/登录限制保留状态；资源扫描结束记录未扫描入口和预算原因。

生产实现没有五所测试大学的域名分支，没有给它们新增学校包。HTML样本用于验证共享结构，不能作为运行时特判。

## 仍然不足

- 来源发现每轮最多48次请求、深度3；队列48项。通知来源有实际下一页链接才开启最多3页历史读取。资源每轮最多32页。五校报告中的 budget_exhausted / pending_frontier 说明仍未扫描的入口，因此本轮不通过“全校全量”验收。
- 通知总量增加仍不能证明考试、缴费、竞赛、奖助等每个类别完整。具体已收录与漏掉的重点样本以上表为准，全部逐项差异见CSV。
- 未知日期仍较多。复用已验证正文解决了一部分；其余通知没有批量读完正文，默认今年视图不会把它们猜成今年。需要进一步建设可恢复的正文补全任务与日期证据来源。
- 外部就业平台、微信链接、纯附件通知、动态列表及校内系统不自动扩展请求域；保留出处或状态，后续通过可复用适配器扩展。图书馆入口可访问不能证明学校当前购买了每个数据库。
- 首页新闻与实用通知尚未完全区分。大学官网内容量大，后续应按栏目语义、事项类型与学习阶段排序，而不是只追求列表条数。

下一轮通用工作优先级：①按 pending_frontier 持久化增量续扫及覆盖进度，避免每次从首页重新开始；②按重修/补考/缴费/申请等重要性补足缺日期正文，并记录日期出处；③继续补共享CMS的动态接口、附件与跨平台官方链接；④围绕重点通知的遗漏率做验收，另选全新学校验证，防止对本组样本过拟合。

## 使用本地验证包

五校测试包基于0.1.2源码，程序版本字段仍为0.1.2，属于本地通用采集整改验证版。五校结果冻结于 shared-fixes-v4，保留其当时构建与证据。之后的最终共享整改和北邮复测随 `v0.1.2-r1` 更新预览版发布，已有 GitHub `v0.1.2` 附件未替换；当前下载见[安装说明](windows-release.md)，最终验证见[北邮教务指南验收](bupt-generic-crawling-validation.md)。

便携包与完整运行证据保存在本机审计目录 `D:\codex项目\CampusPulse官网对比审计\2026-10-04`。程序目录为 `builds/shared-fixes-v4/CampusPulse/`。普通启动运行 CampusPulse.exe；隔离复现请使用独立 --database / --settings-dir / --onboard-output，待默认学校初始更新完成，再输入目标官网。不能导入这里生成的学校草案作为“陌生大学自动发现”测试输入。

五校本机验收未覆盖当前安装软件，未修改已有订阅、待办或个人提醒。后续发布以新的 Git 提交和 `v0.1.2-r1` 标签保存最终共享代码，不改写此处冻结的 v4 实网数字。
