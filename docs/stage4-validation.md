## 主题与采集完善

增加独立 `payment`（缴费）主题，与标题含重修的既有 `retake_payment` 主题分别匹配。通知页和订阅页调用同一匹配器；旧缓存应用新的分类规则，无需重写用户数据库。标题仍分别显示重修、补考、缴费，多词用 ` / ` 连接。社会实践、学术报告、运动会、挑战杯、学费减免、勤工助学等补充关键词支持相应主题。正文中出现缴费/交费的通知在正文缓存后也能命中缴费主题；列表未读取正文时无法据此判断。

通用静态解析支持十六进制详情路径、`.jhtml`、北华列表行布局、嵌套标题、日期属性和行内日期、多种正文容器。只有本主机的 HTTP 锚点可升级 HTTPS；认证信息、显式端口和不可信域名拒绝。未知年份不从标题推断。静态栏目存在同目录详情时过滤其他目录的侧栏链接，避免误选不相关且受限的正文作为栏目样本。

自动接入验证官方入口自身的列表，并在每个来源启用前校验一条正文；24页请求上限、3秒间隔和真实HTML证据保留。登录和访问失败进入完整来源目录，保留原始入口与错误。学校新增只增加可信身份/部门入口的JSON包，未添加大学专属C++分支。

## 日历、ICS与提醒

日历从个人待办的已确认时间投影，不另外维护截止字段。未知/未确认日期不进入；月份按学校时区显示，完成/取消可切换历史查看。同一任务编辑器更新后，待办和日历同步读取。

实际采用libical 3.0.20序列化ICS：全天事件次日DTEND，准确时刻UTC点事件，稳定UID和revision/SEQUENCE，UTF-8、文本转义、75字节折行。保留原文URL、个人备注、确认来源与说明；完成/取消任务不写VALARM。

版本5增加 `reminder_delivery`。每任务/UTC触发时刻唯一，提交前登记，避免重启或只改备注重复催办。跨学校扫描，完成/取消/禁用停止未触发提醒；应用退出期间不补发已过期触发。运行时15秒检查，最多允许5分钟短延迟，长期错过标为expired。异常和中断可见；submitted代表通道调用完成，不代表用户阅读。

日期、手机导入使用方式和代码入口见 [calendar.md](calendar.md)。
