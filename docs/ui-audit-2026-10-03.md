# CampusPulse 桌面界面审查与品牌模块

审查日期：2026-10-03。平台：Windows / Qt 6.8 Widgets。范围：既有桌面界面、品牌图标、样式、可访问性与新增日历的共用视觉基础。遵循 engineering-suite-ui-audit 的入口及 Impeccable native audit、craft-floor；按 Windows 桌面使用场景判断，没有套用 iOS/Android 的导航规则。

## 证据与验收边界

本次先检查 `src/desktop` 源码及 2026-10-02 的 `evidence/jlu-ai-entry.png`、`evidence/jlu-retake-result.png`，再实现独立品牌模块。没有操作桌面 1，没有发送鼠标或键盘动作。

`evidence/brand-probe` 是静态库、Qt 资源、Windows RC 和离屏样式的独立编译验证。该程序强制 `QT_QPA_PLATFORM=offscreen`，截图是合成控件样本，不是完整 CampusPulse 的运行验收。Offscreen 没有 Windows 系统外观服务，暗色由调色板模拟；结果 JSON 显式记录 `dark_appearance_simulated=true` 与 `product_ui_verified=false`。真实软件、屏幕缩放、屏幕阅读器和系统主题切换仍须以主程序在桌面 2 的后续验收为准。

## 原始界面代码评分

以下评分描述本次修改前的源代码和旧截图，不作为修改后的真实 UI 得分。

| 维度 | 分数 / 4 | 已核实的问题 |
|---|---:|---|
| 可访问性 | 2 | 查询框缺明确 accessibleName，样式没有稳定键盘焦点提示，正文全部锁定为 13px |
| 性能 | 3 | 使用 Qt item model、按需读取正文；本次没有长列表性能或启动耗时实测 |
| 外观与主题 | 1 | MainWindow 内联颜色和固定字体；部分状态与错误标签又写局部颜色 |
| 原生平台一致性 | 3 | 标准窗口、表格、分隔器、编辑器；exe 和窗口仍使用通用 Qt 图标 |
| 自适应 | 2 | 支持可调分隔器和滚动编辑器，但筛选横排、固定表格列宽没有窄窗口布局 |

界面采用原生 Qt 控件，能辨识为 Windows 桌面软件。主要问题集中在共享样式与信息密度，不需要替换业务页面或移动已有操作。

## 按影响排序的发现

1. **P1：全局固定 13px 字体与缺少明确焦点样式。** 原位置 `MainWindow.cpp` 的内联样式。字号不能沿用用户系统字体偏好，键盘操作时难以辨认当前输入或按钮。已在 `BrandTheme` 中改用系统字体的 pt 尺度、相对层级，并为输入、按钮、列表、表格和 tab 提供焦点样式。进一步在桌面 2 检查 100%、150% 和较大系统字体。建议 `/impeccable harden`。

2. **P1：搜索、年份、主题等输入的辅助技术名称不明确。** 原位置 `NoticePage.cpp`、`TaskPage.cpp`、`UniversityPage.cpp`、`AiSourcesPage.cpp`；placeholder 不能替代稳定的 accessibleName。`BrandTheme::applyWindow` 为这些已有 objectName 的控件补充明确名称，保持控件身份、信号和测试契约。实际 Windows Narrator / UIA 朗读顺序尚未验证。建议 `/impeccable harden`。

3. **P2：散落颜色导致明暗方案不一致。** 原位置 `MainWindow.cpp`、`SourcePage.cpp:194` 等状态前景、两类编辑器局部错误样式。新增统一明暗 token、调色板、状态色 getter，错误和日期周末文字采用经过对比度计算的颜色。主集成已将 SourcePage 状态颜色接入 token，并删除两类编辑器的局部错误样式。Qt `colorSchemeChanged` 会刷新应用和已存在窗口；真实 OS 切换待验收。建议 `/impeccable colorize`。

4. **P2：品牌识别缺失。** 旧截图标题栏和 exe 无 CampusPulse 专属图标。已提供原创“日历 + 脉冲” SVG、7 个尺寸 PNG 与 ICO、7 类导航小图标、Qt qrc 与 Windows RC，并补充 exe 文件属性。图标不含学校专属标志，增加大学无需更改品牌资产。建议 `/impeccable extract`。

5. **P2：来源说明占据通知页面大量纵向空间。** 旧 `jlu-retake-result.png` 中长来源列表随学校覆盖扩展而继续增长，压缩正文和表格。建议通知页仅显示来源数量和覆盖摘要，详细目录保留在现有“来源”页；需要由主集成修改页面文案，本模块保持现有业务结构。建议 `/impeccable distill`。

6. **P2：窄窗口与大字体下筛选横排缺少换行布局。** `NoticePage.cpp` 的年份、查询、主题、清除、更新均在同一横排；来源和待办表格有固定列宽。建议支持筛选分两行，给标题列优先空间，必要时明确可用最小窗口尺寸；不得把增加图标当成布局修复。已有 title/url tooltip 提供截断文字的查看方式，不能误报为标题丢失。建议 `/impeccable adapt`。

7. **P2：待办提醒文案仍写“下一步日历功能启用后使用”。** 原 `TaskEditorDialog.cpp`。第四步加入软件内日历、ICS 和运行中提醒时，主集成已同步这一旧文案；还需在运行验收与使用说明明确退出应用后的提醒边界，避免保存偏好被理解为已启动后台常驻。建议 `/impeccable clarify`。

未从本次证据确认 P0 界面阻塞。没有为常规原生控件虚构触摸手势、移动安全区域或动画问题。

## 已交付模块及集成

`src/desktop/BrandTheme.h/.cpp` 提供：

- `installApplication(QApplication&)`：程序构造 QApplication 后设置应用图标、系统字体、明暗调色板和共用样式。
- `applyWindow(QWidget&)`：窗口创建子控件后替换旧内联样式，补充可访问名称、周末日历颜色和窗口图标；不改控件 objectName。
- `applicationIcon()`：Qt 窗口使用 16、24、32、48、64、128、256 尺寸 PNG，避免额外 SVG 解码依赖。
- `navigationIcon(page)`：`notices`、`sources`、`subscriptions`、`tasks`、`calendar`、`universities`、`ai`。
- `statusColor(StatusTone)`：统一 neutral、success、warning、error 的明暗状态色。

CMake 开启 `CMAKE_AUTORCC`，在 `campus_desktop` 加入 `BrandTheme.cpp` 与 `assets/campuspulse.qrc`；Windows exe 加入 `assets/campuspulse.rc` 并将 assets 加入 target include path。qrc 位于静态库，通过 `Q_INIT_RESOURCE` 保证主程序和 Qt 测试链接时不被丢弃。

资产由 `tools/generate-brand-assets.py` 重现。脚本只在开发时使用 Pillow，没有下载外部图标、调用模型或给安装包增加 Python 依赖；SVG 为原始矢量，PNG/ICO 的几何与颜色使用同一原创图形规则。
